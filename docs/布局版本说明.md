## 布局优化版

分支：`codex/topology-layout-polish`。

设备区按列对齐，通信交换与网络安全监测各占一列。两台交换机仍在设备分层区域外，业务接入线仍沿层间空隙排列；授时系统与合并单元保持垂直直连。两条 IDS 镜像支路的端点对齐，监测区域增加了背景边框。

页面收窄左右侧栏，压缩空状态面板，把更多空间用于拓扑。长设备名自动换行，缩放按钮和比例移到独立工具栏。新增“展开拓扑”：隐藏两侧详情面板，按新视口自动适配；再次点击或按 Esc 恢复，选择设备或交换机、IDS 时也会恢复对应详情面板。展开不会停止仿真，原有推演状态继续保留。

改动文件包括三份 `scenarios/substation-*.json` 的布局配置、`sim2030/presentation/static/app.js`、`index.html`、`style.css`，以及 `tests/test_network_topology.cjs`。设备、业务连接和检测算法未作调整。

## 验证方式

```powershell
node --check sim2030/presentation/static/app.js
node --test tests/test_network_topology.cjs
python -m unittest tests.test_network_deployment -q
```

前端测试检查全部场景中设备的分层边界、交换机外置、层间走线、镜像接口对齐和授时直连。浏览器检查桌面、笔记本及窄窗口布局，展开与恢复、节点详情、缩放重置、场景切换和报文详情。
