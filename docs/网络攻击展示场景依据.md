# 网络攻击前端展示

## 选择的攻击类型

第一版展示“已受控主机发出未授权控制命令”。INL 的 CyOTE 报告记录了 2015 年乌克兰电网攻击中，攻击者利用已获得的访问权限操作 HMI 或控制客户端，打开变电站断路器的情况。报告第 2.2 节说明事件背景，第 3.9 节分析未授权命令与相关观测线索。

资料：[INL《Ukraine Energy Sector Cyber Attack 2015》](https://cyote.inl.gov/content/uploads/24/2025/12/CyOTE-Case-Study_Ukraine-2015.pdf)。报告发表于 2022 年，引用的是历史事件。

MITRE ATT&CK 将未授权命令描述为超出预期操作或不满足业务前提的控制请求，并指出可结合设备日志、异常连接、命令功能和业务状态调查。IDS 从已有合法主机看到一条控制报文，并不足以单独证明攻击成立。

资料：[MITRE ATT&CK：Unauthorized Message / Command Message](https://attack.mitre.org/techniques/T0855/)。该旧链接当前显示的技术编号为 T1692.001，历史资料通常使用 T0855；查阅日期为 2026-10-11。

## 在本项目中的表达

新场景 `substation-network-attack` 从 `substation-live` 复制，只改变场景标识、名称，并在 `layout.cyber_demo` 中增加展示阶段。基础设备、通信关系、运行参数、操作计划、识别与防御配置保持一致。

假设攻击者已控制站控主机。本项目用既有的“站控主机 → 站控网交换机 → 测控装置 → 过程网交换机 → 断路器智能终端 → 控制硬接线 → 断路器”关系组织展示。该路径是项目的情景设计，不表示乌克兰事件采用相同设备、协议或拓扑，也没有把此路径当作所有实际变电站的统一接线。

页面提供七个阶段：正常基线、主机受控、异常命令、命令下传、执行风险、监测线索、核验与处置。左侧可选择阶段、向前或向后查看，以及重置。红色虚线标示命令路径，紫色虚线标示镜像／上报路径，橙色框表示风险或监测关注点。

阶段选择只改变前端展示，不提交攻击动作，不构造网络报文，不修改断路器状态，不向观测、识别或防御记录添加演示结果。节点内数值继续来自正常仿真；实际 IDS 区域在未接入数据时仍显示暂无采集数据。展示动画随主推演按钮和四档倍速运行、暂停。

## 后续功能的依据要求

若以后接入真实检测或攻击仿真，需要明确控制协议、资产与端口映射、操作授权基线、观测数据来源和影响模型。GOOSE 重放／伪造、拒绝服务等可作为后续候选方向，本版没有实现，也没有宣称它们与本例属于同一种攻击。

## 验证

```powershell
node --test tests/test_cyber_demo.cjs tests/test_network_topology.cjs tests/test_simulation_player.cjs
python -m unittest tests.test_network_attack_scene tests.test_network_deployment -q
```

测试检查展示路径引用、跨网接口关系、阶段切换与重置、基础场景配置一致性，并确认运行新场景不会产生攻击作用或伪造 IDS 告警。
