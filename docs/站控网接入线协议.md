## 注：调压和冷却"控制接口"到底用的什么协议

先厘清一个关键点：调压/冷却每条支路其实分**两段**，你问的"控制接口协议"对应的是**网络段**这一段：

```
测控装置 ──(过程网，网络段)──→ 分接机构控制接口 ──(硬接线)──→ 变压器(有载分接)
测控装置 ──(过程网，网络段)──→ 冷却系统控制接口 ──(硬接线)──→ 冷却风机
```

### 1. 直接结论（本项目口径）

- **调压控制 `L-mc-tap`、冷却控制 `L-mc-cool` 没有固化到某个具体协议。** 依据 `docs/架构图依据说明.md`：
  - R15（有载分接调压，参考 Reinhausen TAPCON 230）：*"期望电压设置与**按型号选择的通信接口**；调压控制器功能可与就地接口集成"*。
  - R16（冷却，参考 Hitachi CoreSense+ / Reinhausen ETOS TD）：*"冷却风机控制与油温监测；分级冷却系统包含风机/泵……具体……另按实例确认"*。
- 因此在**仿真底座内部**，这两条 `wired` 链路只承载内部 `command`（设定/启停）与 `feedback`（执行反馈）业务消息，**不实现任何真实协议栈**。语义上它们与 GOOSE 跳闸、SV 采样并列，但不套用跳闸语义。

### 2. 若要"具体到某个协议"，工程上的可选范围（参考设备，非本项目固化）

**调压（有载分接 / OLTC 自动调压，参考 TAPCON 230）：**

| 可选通信接口                 | 说明                         |
| ---------------------- | -------------------------- |
| IEC 61850（MMS + GOOSE） | 数字变电站接入，监视分接位置、下发期望电压/升降档  |
| Modbus RTU / TCP       | 常见就地/站端接入方式                |
| IEC 60870-5-101 / -104 | 远动接入                       |
| DNP3                   | 北美系统常见                     |
| 串口（RS-232/485）或光纤      | 就地接入                       |
| 硬接点（升/降档指令）            | 就地集成时，控制器与驱动就地接线，不经间隔层逐次升降 |

R15 特别强调"调压控制器功能可**与就地接口集成**"，意味着升降档也可由就地控制器闭环执行，站端/间隔层只下发设定并接收状态，不一定每次都走 GOOSE。

**冷却（分级冷却，参考 CoreSense+ / ETOS TD）：**

| 可选实现                 | 说明                                      |
| -------------------- | --------------------------------------- |
| 继电器/接触器硬接点（分级启停）     | **最常见的实际做法**：风机/泵分组按油温阈值分级投切，命令本质是二进制接点 |
| Modbus RTU / TCP     | 数字化后远程监视与启停                             |
| IEC 61850（MMS/GOOSE） | 并入站内自动化时的监视/控制                          |

R16 明确"分级冷却系统包含风机/泵"，且"调速及具体热模型另按实例确认"——即冷却默认是**分级启停**，不是无级调速，因此现场多以**接点/接触器硬接线**实现，数字化后才有 Modbus/IEC 61850 的监视与控制。

### 3. 落到这个场景里的最终判断

- **网络段（测控装置 ↔ 控制接口）**：`L-mc-tap`、`L-mc-cool` 在过程网上跑，协议**未固化**，仿真用内部 `command`/`feedback` 消息；工程上最可能的对应是 **<mark>GOOSE 或厂商专用（调压）</mark>**、**<mark>接点/硬接线为主（冷却，数字化则为 Modbus/IEC 61850）</mark>**。
- **硬接线段（控制接口 ↔ 一次/辅助设备）**：`L-ctl-tap-down`、`L-ctl-cool-down` 是**电气硬接线**，无通信协议。





### 汇总

- **过程网 6 条接入线**：按业务端口再细分——
  - **SV**（采样值）：合并单元 → 测控装置、合并单元 → 过流保护装置；
  - **GOOSE**（跳闸/开关控制）：过流保护装置 → 断路器智能终端、测控装置 ↔ 断路器智能终端；
  - **调压/冷却控制接口**：测控装置 → 分接机构控制接口、测控装置 → 冷却系统控制接口。
- 一条接入线可以同时运送**多对设备**的数据：典型如"站端监控系统 ETH-ST/P1"同时承载 `L-station-mc` 与 `L-prot-station`；"合并单元 ETH-PR/P6"同时向测控装置和过流保护装置发布 SV。
